EcoLoop プライバシーポリシー

最終更新日: 2026年8月2日

H Labs Works（以下「当方」）は、モバイルアプリケーション「EcoLoop」（以下「本アプリ」）におけるユーザーの個人情報の取り扱いについて、以下の通り定めます。

1. アプリの概要と基本方針

EcoLoop は、カメラで捉えたごみの分別区分を判定し、お住まいの自治体のルールに沿った捨て方を案内するアプリケーションです。

ごみの判定（AI 認識・材質マークの読み取り）は、すべてお使いの端末内で実行されます。カメラに映った映像が判定のために外部へ送信されることはありません。

2. 収集する情報

2.1 端末内にのみ保存する情報

以下の情報はお使いの端末内にのみ保存され、外部に送信されることはありません。

情報目的保存場所
自治体のごみ分別ルール分別区分・収集日の案内端末内のみ（SQLite）
アプリ設定（言語・表示サイズ・地区・寄贈の同意状態等）アプリの動作設定端末内のみ
AI モデルファイル端末内での画像認識端末内 または microSD カード

2.2 学習データの寄贈（任意・明示同意制）

設定画面の「学習データの寄贈に協力する」をユーザーご自身が有効にした場合に限り、分別を手入力で確定・訂正した際の対象物の画像を、AI の認識精度向上のための学習データとして当方に送信します。既定では無効です。

送信されるもの送信されないもの
・対象物の画像（判定対象を切り抜いたもの）
・品目の分類名（例:「乾電池」）
・アプリのバージョン
・匿名の識別子（ランダムに生成される ID） 		・氏名・メールアドレス等の個人を特定する情報
・撮影場所（位置情報）※画像に位置情報は含まれません
・端末の広告 ID・端末識別子
・連絡先・通話履歴・その他の端末内データ

人物の自動除外: 画像内に人物が検出された場合、同意済みであっても送信を自動的に中止します。この判定は端末内で行われ、人物が写った画像が端末外に出ることはありません。

同意の撤回: 設定画面からいつでも無効にできます。無効にした以降、画像が送信されることはありません。

寄贈された画像は当方が管理する非公開のストレージに保存し、本アプリの AI モデルの学習にのみ利用します。第三者への提供・販売は行いません。

2.3 カメラ

ごみの分別判定のために使用します。映像は端末内で処理され、2.2 の明示的な同意による寄贈を除き、外部に送信されることはありません。

2.4 位置情報

収集スケジュールを表示するための地区判定に、ユーザーの操作（「現在地から探す」）に応じて位置情報を使用します。位置情報は端末内での地区の照合にのみ使用され、当方や第三者に送信・保存されることはありません。

2.5 自動的に収集する情報

本アプリは、広告、行動トラッキング、アクセス解析（Analytics）、クラッシュレポート収集を一切使用していません。

3. 通信を行う場面

本アプリが外部と通信するのは、以下の場合に限られます。

  • 自治体ルールの更新: 当方が公開している静的ファイルを GitHub Pages から取得します（通常の HTTPS GET のみ。端末内のデータは送信されません）。
  • AI モデルの更新: ユーザーが「ダウンロード」を選択した場合に、当方が公開しているモデルファイルを GitHub から取得します。
  • 学習データの寄贈: 2.2 の同意がある場合にのみ、対象物の画像を送信します。

通常の Web アクセスと同様に、IP アドレス等の接続情報が GitHub のサーバーに記録される場合があります。詳細: GitHub Privacy Statement

4. 第三者サービス

寄贈データの受け付けに Google Firebase（Cloud Firestore / 匿名認証 / App Check）を利用しています。匿名認証はアカウント登録を伴わず、ランダムな識別子を発行するのみです。詳細: Google プライバシーポリシー

5. データの第三者提供

当方は、以下の場合を除き、ユーザーの情報を第三者に提供しません。

  • 法令に基づく場合。
  • ユーザーの同意がある場合。

6. データの保管と削除

  • 端末内のデータ（ルール・設定・AI モデル）は、アプリをアンインストールすることですべて削除されます。
  • 寄贈された画像は、AI モデルの学習に必要な期間保存します。
  • 寄贈した画像の削除をご希望の場合は、下記の窓口までご連絡ください。寄贈は匿名で行われるため個々の投稿とご本人を結びつける情報を当方は保持していませんが、寄贈日時・品目名など特定に必要な情報をお知らせいただければ、該当データの削除に努めます。

7. 児童のプライバシー

本アプリは 13 歳未満の児童を対象としておらず、意図的に 13 歳未満の児童から個人情報を収集することはありません。

8. プライバシーポリシーの変更

当方は、必要に応じて本ポリシーを変更する場合があります。重要な変更がある場合は、本ページにて告知します。
